# Reaction and motor task analysis

Website: https://benson0875.github.io/reaction-motor-analysis-web/

Import SD files or use read-only USB synchronization in supported Chrome/Edge. Records remain in the browser. Charts and deterministic summaries work without a model.

## Local WebLLM assistant

Under Compare or Results, select the interpretation button. Expand model settings and explicitly download a Qwen model if desired. No login or API key. HTTPS/localhost, WebGPU and sufficient GPU memory are required. Downloads are roughly 1GB (1.5B) or 400MB (0.5B), estimates only. Model files come from Hugging Face/MLC; those hosts receive network metadata. Data/questions are processed locally. Stop releases the model worker; downloaded cache can remain in browser storage.

The LLM selects observation IDs from a deterministic, deidentified summary. Displayed figures/text come from checked observations. Invalid responses fall back to deterministic summaries. This is bounded data interpretation, not unrestricted medical chat. Individual peer comparisons exclude all of the same participant's sessions. Repeated sessions are not independent people. Descriptive plots do not relax formal quality gates.

## Validation and limits

Passed local facts, CRC/protocol/USB/environment regressions and real Chromium desktop/mobile flows. The actual bundled WebLLM Worker imports correctly. Controlled model substitutes verify ready/answer/cancel behavior. **Actual GPU model download/inference, model selection accuracy, memory, latency and offline model-cache reuse remain unverified.** This limitation is intentional release documentation, not a claim that inference has passed.

No participant records or model weights are in this repository. Demo records are synthetic. Firmware is unchanged.

## Rebuild

Pinned WebLLM 0.2.89; license notices in webllm-licenses. To rebuild the Worker, install project dependencies with `npm ci --ignore-scripts`, then use Bun: `bun build src/webllm-worker-entry.js --target browser --format esm --minify --outfile webllm-worker.js`. The static HTML is generated by tools/build-site.py. Serve on HTTPS or localhost; file:// still supports charts, not the model Worker.
